# launch-desk

Two-bot launch relay for **Global Hack Week: Hacktoberfest** — Challenge 7.

Source page: [Hacktoberfest 2026](https://hacktoberfest.com/)

## Deliverables

| File | Purpose |
| --- | --- |
| `source-brief.md` | Verified facts and announcement constraints |
| `announcement-draft.md` | 120–180 word draft announcement |
| `run-of-show.csv` | Launch schedule (Time, Owner, Action, Status) |
| `qa-notes.md` | QA verdict (**Pass**) |
| `bot-handoff-log.md` | Source Editor → Launch Producer handoff record |

Nothing here is published or sent externally.
