# Challenge 7: Two-Bot Launch Relay — playbook

Event: [Global Hack Week: Hacktoberfest](https://events.mlh.io/events/14553-global-hack-week-hacktoberfest)  
Challenge: [Run a Two-Bot Launch Relay](https://www.mlh.com/events/global-hack-week-open-source-90/challenges/01a11d2f-72db-39ff-651a-7d7f867a60c4/submissions/new)

This folder already contains sample deliverables using **https://hacktoberfest.com/** as the source. For a valid submission you must still run the **Source Editor → Launch Producer** handoff in Cursor Bots (cloud) so your screenshot shows one bot invoking the other.

## 1. Bot settings (paste into each Bot → Settings → Job or Instructions)

**Source Editor**

> Verify facts, preserve source links, use Unknown for missing information, and save work as `launch-desk/source-brief.md`. Ask before contacting anyone or publishing.

**Launch Producer**

> Read an approved brief and create a 120- to 180-word `launch-desk/announcement-draft.md` plus `launch-desk/run-of-show.csv` with at least five rows. The run of show must use the columns Time, Owner, Action, and Status. Use only the approved brief. Ask before sending, publishing, purchasing, or changing an external system.

## 2. Open this repo on the shared cloud computer

Use a Cursor cloud workspace whose project root contains the `launch-desk` folder (this directory).

## 3. Source Editor — first message (edit brackets)

```
Build the brief from https://hacktoberfest.com/. Use these announcement constraints: Audience: students and early-career developers curious about open source and open-weight AI; Tone: welcoming, energetic, inclusive; Call to action: Sign in with MyMLH at Hacktoberfest and join at least one online activity in October. Verify facts, preserve source links, use Unknown for missing information, save the brief as launch-desk/source-brief.md, and stop for my approval before handing it to Launch Producer. Do not contact anyone or publish anything.
```

Review `source-brief.md`, fix any facts, then reply:

```
Brief approved. Invoke Launch Producer, wait for announcement-draft.md and run-of-show.csv, and bring the results back into this chat.
```

## 4. QA in the same Source Editor chat

```
Compare announcement-draft.md and run-of-show.csv to the approved brief and save launch-desk/qa-notes.md with Pass or a short fix list. If fixes are needed, route only those fixes to Launch Producer.
```

## 5. What to submit

1. Screenshot: Source Editor invoking Launch Producer and returning results in one thread.
2. Full `announcement-draft.md` and `run-of-show.csv` (or screenshots).
3. Screenshot: `launch-desk` folder listing + `qa-notes.md` showing **Pass**.
